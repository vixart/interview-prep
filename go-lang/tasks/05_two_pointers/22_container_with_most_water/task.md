# 5.2. Контейнер с максимальным количеством воды

Раздел: `05_two_pointers / 22_container_with_most_water`

## Условие

Дан массив `height`, где `height[i]` представляет высоту вертикальной линии на позиции `i`.
Необходимо найти две линии, которые вместе с осью X образуют контейнер,
содержащий максимальное количество воды.

Площадь = расстояние между линиями × минимальная высота из двух линий.

## Требования

- Сложность по времени `O(n)`.
- Использовать технику двух указателей.

## Примеры

```
Input:  height = [1,8,6,2,5,4,8,3,7]
Output: 49
Объяснение: максимальная площадь между индексами 1 и 8: (8-1) * min(8,7) = 49

Input:  height = [1,1]
Output: 1
Объяснение: площадь между индексами 0 и 1: (1-0) * min(1,1) = 1

Input:  height = [4,3,2,1,4]
Output: 16

Input:  height = [1,2,1]
Output: 2
```
