# 5.5. Удаление дубликатов из отсортированного массива in-place

Раздел: `05_two_pointers / 25_remove_duplicates_in_place`

## Условие

Дан отсортированный по возрастанию массив `nums`.
Необходимо удалить дубликаты in-place так, чтобы каждый элемент встречался только один раз.
Вернуть длину нового массива.

## Требования

- Изменить массив in-place с `O(1)` дополнительной памятью.
- Сложность по времени `O(n)`.
- Использовать технику двух указателей.

## Сигнатура

```go
func removeDuplicates(nums []int) int { return 0 }
```

## Примеры

```
Input:  nums = [1,1,2]
Output: 2, nums = [1,2,_]
Объяснение: первые 2 элемента nums должны быть [1,2]

Input:  nums = [0,0,1,1,1,2,2,3,3,4]
Output: 5, nums = [0,1,2,3,4,_,_,_,_,_]
Объяснение: первые 5 элементов nums должны быть [0,1,2,3,4]
```
