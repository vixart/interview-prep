# 5.4. Наименьшая разница по модулю между двумя массивами

Раздел: `05_two_pointers / 24_min_absolute_difference`

## Условие

Даны два массива. Нужно найти наименьшую разницу по модулю между любым элементом
первого массива и любым элементом второго массива.

## Входные данные

- `arr1: []int` — первый массив
- `arr2: []int` — второй массив

## Выходные данные

- `int` — наименьшая разница по модулю между элементами двух массивов

## Сигнатура

```go
func minAbsoluteDifference(arr1 []int, arr2 []int) int { return 0 }
```

## Пример

```
arr1 = [1, 10, 15, 4, 20]
arr2 = [3, 16, 5, 7]
Результат: 1 (разница между 4 и 5, или между 15 и 16)
```
