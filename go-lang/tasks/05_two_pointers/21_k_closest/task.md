# 5.1. K ближайших элементов в отсортированном массиве

Раздел: `05_two_pointers / 21_k_closest`

## Условие

Дан отсортированный по возрастанию список целых чисел `arr` и индекс элемента `index`.
Необходимо вернуть в любом порядке `k` чисел из списка, которые являются ближайшими
к элементу `arr[index]`.

## Ограничения

- Размер списка `1 <= N <= 10^6`
- Элементы списка: `-10^9 <= arr[i] <= 10^9`
- Число `0 <= k <= N`
- Индекс элемента `0 <= index < N`
- Среди двух одинаково отдалённых элементов выбирается больший

## Сигнатура

```go
func findKClosest(arr []int, index int, k int) []int { return nil }
```

## Примеры

```
findKClosest(arr=[2, 3, 5, 7, 11], index=3, k=2)  → [5, 7] или [7, 5]
findKClosest(arr=[4, 12, 15, 15, 24], index=1, k=3) → [12, 15, 15]
```
