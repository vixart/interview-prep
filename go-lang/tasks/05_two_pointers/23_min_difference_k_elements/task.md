# 5.3. Минимальная разница между k элементами

Раздел: `05_two_pointers / 23_min_difference_k_elements`

## Условие

Дан массив чисел и целое число `k`. Нужно выбрать любые `k` чисел из массива так,
чтобы разница между максимальным и минимальным из них была наименьшей,
и вернуть эту минимальную разницу.

## Входные данные

- `nums: []int` — массив чисел
- `k: int` — количество элементов для выбора

## Выходные данные

- `int` — минимальная разница между максимальным и минимальным из `k` выбранных элементов

## Сигнатура

```go
func minDifference(nums []int, k int) int { return 0 }
```

## Пример

```
nums = [1, 3, 5, 7, 9], k = 3
Можно выбрать [1, 3, 5] -> разница = 5 - 1 = 4
Можно выбрать [3, 5, 7] -> разница = 7 - 3 = 4
Можно выбрать [5, 7, 9] -> разница = 9 - 5 = 4
Результат: 4
```
