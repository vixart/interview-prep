# 3.1. Анаграммы

Раздел: `03_strings / 11_anagram`

## Условие

Определить, являются ли две строки анаграммами.

Строка A — анаграмма строки B, если можно переставить местами символы в строке A
и получить строку B.

## Требования

- Регистр символов учитывается.
- Пробелы учитываются.
- Пустая строка — анаграмма пустой строки.

Возможны два подхода: через хеш-таблицу (частотную карту) и через сортировку.

## Сигнатура

```go
func IsAnagram(a, b string) bool { return false }
```

## Примеры

```
IsAnagram("лапоть", "пальто") → true
IsAnagram("listen", "silent") → true
IsAnagram("hello", "world")   → false
IsAnagram("", "")             → true
IsAnagram("a", "b")           → false
```
