# 1.3. Произведение всех элементов кроме i-го

Раздел: `01_arrays_and_slices / 03_product_except_self`

## Условие

Есть массив целых чисел. Нужно написать функцию, которая вернёт массив такого же размера,
где на каждой i-ой позиции будет произведение всех элементов кроме i-го.

## Требования

- Решить без использования деления.

## Сигнатура

```go
func productExceptSelf(nums []int) []int { return nil }
```

## Примеры

```
productExceptSelf([1, 2, 3])    → [2*3, 1*3, 1*2] → [6, 3, 2]
productExceptSelf([1, 2, 3, 4]) → [24, 12, 8, 6]
```
