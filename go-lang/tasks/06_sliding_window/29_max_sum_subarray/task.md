# 6.4. Максимальная сумма подмассива длины k

Раздел: `06_sliding_window / 29_max_sum_subarray`

## Условие

Дан массив целых чисел `nums` и целое число `k`.
Необходимо найти максимальную сумму подмассива длины `k`.

## Требования

- Сложность по времени `O(n)`.
- Использовать технику скользящего окна фиксированного размера.

## Сигнатура

```go
func maxSumSubarray(nums []int, k int) int { return 0 }
```

## Примеры

```
Input:  nums = [2,1,5,1,3,2], k = 3
Output: 9
Объяснение: подмассив [5,1,3] имеет максимальную сумму 9

Input:  nums = [2,3,4,1,5], k = 2
Output: 7
Объяснение: подмассив [3,4] имеет максимальную сумму 7

Input:  nums = [1,4,2,10,23,3,1,0,20], k = 4
Output: 39
Объяснение: подмассив [4,2,10,23] имеет максимальную сумму 39
```
