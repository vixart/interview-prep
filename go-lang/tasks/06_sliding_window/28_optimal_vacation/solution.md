# Решение

## Подход

скользящее окно длиной `vacationLength` по дням `1..periodLength`;
так как `daysWithMeetings` разрежен и отсортирован, окно удобно двигать
по массиву встреч двумя указателями, суммируя встречи внутри окна,
и выбирать окно с минимальной суммой (при равенстве — самое раннее).
Последний возможный день старта — `periodLength - vacationLength + 1`.
