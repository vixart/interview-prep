# 6.1. Максимум в скользящем окне

Раздел: `06_sliding_window / 26_max_sliding_window`

## Условие

Дан массив `nums` и целое число `k`. В массиве есть скользящее окно размера `k`,
которое движется слева направо. Вы видите только `k` чисел в окне.
Для каждой позиции окна необходимо вернуть максимальный элемент.

## Требования

- Сложность по времени `O(n)`.
- Использовать эффективную структуру данных (deque/очередь с двумя концами).

## Сигнатура

```go
func maxSlidingWindow(nums []int, k int) []int { return nil }
```

## Примеры

```
Input:  nums = [1,3,-1,-3,5,3,6,7], k = 3
Output: [3,3,5,5,6,7]
Объяснение:
  Окно [1,3,-1]  → max = 3
  Окно [3,-1,-3] → max = 3
  Окно [-1,-3,5] → max = 5
  Окно [-3,5,3]  → max = 5
  Окно [5,3,6]   → max = 6
  Окно [3,6,7]   → max = 7

Input:  nums = [1], k = 1
Output: [1]
```
