# 6.5. Подмассив с заданной суммой (минимальная длина)

Раздел: `06_sliding_window / 30_subarray_sum_equals_k`

## Условие

Дан массив положительных целых чисел `nums` и целое число `k`.
Необходимо найти длину самого короткого подмассива, сумма которого `>= k`.
Если такого подмассива нет, вернуть `0`.

## Требования

- Сложность по времени `O(n)`.
- Использовать технику динамического скользящего окна (переменного размера).

## Сигнатура

```go
func minSubArrayLen(nums []int, k int) int { return 0 }
```

## Примеры

```
Input:  nums = [2,3,1,2,4,3], k = 7
Output: 2
Объяснение: подмассив [4,3] имеет минимальную длину 2 и сумму >= 7

Input:  nums = [1,4,4], k = 4
Output: 1
Объяснение: подмассив [4] имеет длину 1 и сумму = 4

Input:  nums = [1,1,1,1,1,1,1,1], k = 11
Output: 0
```
