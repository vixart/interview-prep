# 4.4. Определение чемпионов соревнований

Раздел: `04_hash_tables / 19_find_champions`

## Условие

Дана статистика соревнований по шагам: для каждого дня соревнований — список
участников и количество шагов, которое каждый из них прошёл за этот день.
Нужно определить чемпионов.

## Входные данные

- `statistics [][]UserSteps` — внешний слайс: дни соревнований;
  внутренний слайс: результаты участников за этот день (`UserId`, `Steps`).

## Выходные данные

Структура `Champions`:
- `UserIds []int` — список ID пользователей-чемпионов;
- `Steps int` — общее количество шагов чемпионов.

## Требования

- Чемпионом может стать только тот, кто участвовал во ВСЕХ днях соревнований.
- Среди таких участников выбираются те, у кого максимальная сумма шагов.

## Сигнатура

```go
type UserSteps struct {
    UserId int
    Steps  int
}

type Champions struct {
    UserIds []int
    Steps   int
}

func findChampions(statistics [][]UserSteps) Champions {
    return Champions{}
}
```

## Примеры

```
statistics = [
    [{userId: 1, steps: 1000}, {userId: 2, steps: 1500}],
    [{userId: 2, steps: 1000}],
]
Результат: {userIds: [2], steps: 2500}

statistics = [
    [{userId: 1, steps: 2000}, {userId: 2, steps: 1500}],
    [{userId: 1, steps: 3500}, {userId: 2, steps: 4000}],
]
Результат: {userIds: [1, 2], steps: 5500}
```

Замечание: во втором примере оба участника были во всех днях и набрали
одинаковую сумму `5500`, поэтому чемпионов двое.
