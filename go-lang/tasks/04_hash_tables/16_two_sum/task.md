# 4.1. Two Sum — поиск суммы в массиве

Раздел: `04_hash_tables / 16_two_sum`

## Условие

Напишите функцию, принимающую массив из положительных неупорядоченных чисел
первым аргументом и положительное число вторым аргументом.
Функция должна возвращать `true`, если в массиве есть 2 числа,
которые в сумме дают второй аргумент.

## Сигнатура

```go
func HasSum(nums []int, target int) bool { return false }
```

## Примеры

```
HasSum([10,15,3,7], 17)  → true (10 + 7 = 17)
HasSum([1,2,3,4,5,6], 12) → false
HasSum([5,5], 10)         → true
```

Замечание: ожидается решение за `O(n)` через хеш-таблицу (множество виденных чисел),
а не двойной цикл.
