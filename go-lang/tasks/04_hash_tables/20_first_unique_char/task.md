# 4.5. Первый уникальный символ в строке

Раздел: `04_hash_tables / 20_first_unique_character`

## Условие

Дана строка `s`. Необходимо найти первый неповторяющийся символ и вернуть его индекс.
Если такого символа нет, вернуть `-1`.

## Требования

- Сложность по времени `O(n)`.
- Использовать хеш-таблицу для подсчёта частот.

## Сигнатура

```go
func firstUniqChar(s string) int { return -1 }
```

## Примеры

```
Input:  s = "leetcode"
Output: 0
Объяснение: символ 'l' встречается только один раз, его индекс 0

Input:  s = "loveleetcode"
Output: 2
Объяснение: символ 'v' встречается только один раз, его индекс 2

Input:  s = "aabb"
Output: -1
Объяснение: все символы повторяются
```
