# 4.3. Фильтрация продавцов по городам

Раздел: `04_hash_tables / 18_filter_sellers`

## Условие

Напишите функцию, которая по списку продавцов и их городов определяет,
в каких из заданных городов работает каждый продавец.

## Входные данные

- `sellers: map[int][]string` — ключ: ID продавца, значение: список городов, в которых он работает.
- `cities: []string` — список интересующих городов.

## Выходные данные

- `map[int][]string` — ключ: ID продавца, значение: список городов из `cities`,
  в которых работает продавец.

## Сигнатура

```go
func filterSellersByCities(sellers map[int][]string, cities []string) map[int][]string { return nil }
```

## Пример

```
sellers = {
    1: ["Москва", "Самара", "Ростов"],
    2: ["Москва", "Самара", "Ростов", "Казань", "Курган", "Пенза"],
    3: ["Самара", "Ростов", ...],
    4: ["Москва", "Казань", "Тула"],
}
cities = ["Москва", "Казань", "Тула"]

Результат: {1: ["Москва"], 2: ["Москва", "Казань"], 4: ["Москва", "Казань", "Тула"]}
```

Замечание: продавцы, у которых нет пересечения с `cities` (например, `3`),
в результат не попадают. Ожидается решение через множество `map[string]struct{}`
из `cities` — то есть пересечение множеств, а не двойной цикл.
