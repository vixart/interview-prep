# 4.9.1. Проектирование базы данных для чата

Раздел: `talk_about_solution / 01_chat_and_users`

## Предметная область

Есть 3 сущности: **пользователь**, **чат**, **сообщение**.

### Требования к сущностям

**Пользователь:**
- Имеет имя
- Имеет дату регистрации

**Чат:**
- Имеет название
- Имеет дату создания

**Сообщение:**
- Имеет текст
- Имеет автора
- Имеет дату создания

### Бизнес-правила

1. Пользователь может состоять в **нескольких чатах** одновременно.
2. Сообщение **обязательно принадлежит** одному чату.
3. Сообщение **не может принадлежать** более чем одному чату.

## Задания

1. **Спроектировать схему базы данных:**
   - Описать структуру таблиц
   - Определить первичные и внешние ключи
   - Определить связи между таблицами

2. **Написать SQL запрос:**
   - Выбрать все чаты пользователя "Вася"
   - Формат результата: `(chat_id, chat_name)`
