# 4.9.2. Медленный сервис аналитики

Раздел: `talk_about_solution / 02_slow_service`

Тип задачи: системный дизайн / обсуждение решения.

## Проблема

Есть сервис обработки заказов. В процессе обработки заказа:

1. Пользователь создаёт заказ
2. Сервис заказов отправляет данные в сервис аналитики
3. Сервис аналитики обрабатывает данные (для подсчёта популярности товаров)
4. После этого сервис заказов отправляет ответ пользователю

**Проблема:**
- Сервис аналитики периодически работает **медленно** или **таймаутит**
- Из-за этого мы **не успеваем ответить** пользователю
- В результате **теряем заказы** и **деньги**

## Диаграмма текущего потока

```
+-------+        +--------------+      +------------------+
| User  |        | OrderService |      | AnalyticsService |
+-------+        +--------------+      +------------------+
    |                    |                      |
    | CreateOrder        |                      |
    |------------------->|                      |
    |                    |                      |
    |                    | TrackOrder           |
    |                    |--------------------->|
    |                    |                      |
    |                    |                      | Too long action
    |                    |                      |---------------
    |                    |                      |              |
    |                    |                      |<--------------
    |                    |                      |
    |                    |<---------------------|
    |                    |                      |
    |<-------------------|                      |
    |                    |                      |
```

## Что нужно сделать

Проанализировать поток и предложить, как убрать зависимость ответа пользователю
от медленного сервиса аналитики.
