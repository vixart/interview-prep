# Решение

## Разбор

1. Посчитать `len` и `cap` для каждого среза.
2. Объяснить формулу: для `s[low:high]` → `len = high - low`, `cap = cap(s) - low`.
3. Объяснить, что все срезы делят один backing-массив, поэтому запись в `slice1[0]`
   видна и в `original`, и в `slice2`.
4. Обсудить следствие — утечку памяти: срез из большого массива удерживает
   весь массив в памяти; лечится копированием (`append([]int(nil), s...)` или `copy`)
   и full slice expression `s[low:high:max]`.

## Ответы

```
original: len=10, cap=10, {0, 999, 2, 3, 4, 5, 6, 7, 8, 9}
slice1 [2:5]: len=3, cap=8, {999, 3, 4}
slice2 [3:7]: len=4, cap=7, {3, 4, 5, 6}
```

Замечание: после `slice1[0] = 999` меняется элемент `original[2]`.
