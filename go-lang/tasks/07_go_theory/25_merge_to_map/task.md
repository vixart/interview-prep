# 4.4.4. MergeToMap — объединение значений мапы без дубликатов

## Условие

У вас есть мапа, где ключом является строка, а значением — слайс строк.
Каждый слайс содержит набор уникальных значений для этого ключа.

Вам нужно написать функцию `MergeToMap`, которая принимает мапу и новый слайс
для конкретного ключа, анализирует уже существующие значения в мапе и добавляет только
те элементы из нового слайса, которых там ещё нет.

## Пример входных данных

```go
// Исходная мапа:
m := map[string][]string{
    "group1": {"apple", "banana"},
    "group2": {"carrot"},
}

// Новый слайс:
newValues := []string{"banana", "cherry"}

// Ключ:
key := "group1"
```

## Ожидаемый результат

```go
m := map[string][]string{
    "group1": {"apple", "banana", "cherry"},
    "group2": {"carrot"},
}
```

## Сигнатура

```go
func MergeToMap(m map[string][]string, key string, newValues []string)
```
