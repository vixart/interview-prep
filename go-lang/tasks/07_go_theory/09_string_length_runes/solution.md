# Решение

## Разбор

1. Предсказать вывод программы.
2. Объяснить, почему `len` возвращает не количество символов.
3. Показать, как правильно считать количество символов (рун) в строке.

## Разбор

- В Go строка — это неизменяемая последовательность **байт** в кодировке UTF-8.
- `len(str)` возвращает количество **байт**: `d`=1, `d`=1, `Я`=2, `й`=2, `漢`=3 → **9**.
- `utf8.RuneCountInString(str)` возвращает количество **рун** (символов) → **5**.
- Тот же результат даёт `len([]rune(str))`, но с аллокацией слайса рун.
