# Решение

## Разбор

1. Предсказать размеры обеих структур.
2. Объяснить выравнивание (alignment) и padding: `int32` требует выравнивания по 4 байтам,
   поэтому в `Foo` после `aaa` вставляются 3 байта padding, и ещё 3 после `ccc`.
   В `Bar` два `bool` лежат рядом, padding нужен только один раз.
3. Сделать вывод: порядок полей в структуре влияет на размер — поля стоит
   сортировать от «широких» к «узким».

## Ожидаемый вывод

```
12
8
```
