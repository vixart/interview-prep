# Решение

## Разбор

1. Объяснить, почему такой цикл работает медленно: строки в Go неизменяемы,
   каждая операция `+=` выделяет новую строку и копирует весь накопленный результат →
   `O(n²)` по времени и огромное количество аллокаций (нагрузка на GC).
2. Переписать эффективно через `strings.Builder` (с `Grow` при известном размере),
   показать вариант с `[]byte` + `strconv.AppendInt`.
3. Уметь замерить разницу бенчмарком (`testing.B`, `b.ReportAllocs()`).

## Эталонный вариант

```go
var sb strings.Builder
sb.Grow(100000 * 6)
for i := 0; i < 100000; i++ {
    sb.WriteString(strconv.Itoa(i))
}
str := sb.String()
```
