# 4.2.1. Конкатенация строк: почему это медленно и как ускорить

Тип задачи: вопрос с собеседования «что не так с этим кодом и как исправить».

## Условие

Дан код:

```go
package main

import (
    "fmt"
)

func main() {
    str := ""
    for i := 0; i < 100000; i++ {
        str += fmt.Sprintf("%d", i)
    }
}
```

**Задание:** объясни, почему этот код медленный, и перепиши его эффективно.
