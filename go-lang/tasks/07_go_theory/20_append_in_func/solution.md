# Решение

## Разбор

1. Предсказать вывод.
2. Объяснить две ошибки:
   - в цикле в слайс кладётся адрес **одной и той же** переменной `number`,
     поэтому все три указателя ссылаются на одно значение (`3`);
   - `appendLenWrong` меняет только свою копию заголовка слайса, поэтому
     добавленный элемент снаружи не виден (хотя запись и попала в общий массив,
     `len` у вызывающего не изменился).
3. Показать, как исправить:
   - объявлять переменную внутри цикла (`n := number; numbers = append(numbers, &n)`);
   - функция должна **возвращать** слайс: `func appendLen(numbers []*int) []*int`.

## Ожидаемый вывод

```
3 3 3
```
