# 4.4.6. Случайный порядок обхода мапы

Раздел: `06_random_print`

Тип задачи: вопрос с собеседования «что выведет программа и почему».

## Условие

> Задача: Что выведет программа и почему? Откуда возникает рандом?

```go
package main

import "fmt"

func main() {
    myMap := map[int]string{1: "a", 2: "b", 3: "c"}

    for key, value := range myMap {
        fmt.Println("Key:", key, "Value:", value)
    }
}
```

**Задание:** определи, что выведет программа (и скомпилируется ли она), и объясни почему.
