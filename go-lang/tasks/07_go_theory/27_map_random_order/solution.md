# Решение

## Разбор

1. Ответить: порядок вывода не определён и меняется от запуска к запуску.
2. Объяснить, откуда берётся рандом: runtime намеренно начинает обход
   со случайного бакета и случайной позиции внутри него, чтобы разработчики
   не закладывались на порядок (детали — в `runtime/map.go`, `mapiterinit`).
3. Показать, как получить детерминированный порядок:

```go
keys := make([]int, 0, len(myMap))
for k := range myMap {
    keys = append(keys, k)
}
sort.Ints(keys)

for _, k := range keys {
    fmt.Println("Key:", k, "Value:", myMap[k])
}
```

4. Упомянуть, что `fmt.Println(myMap)` печатает мапу **отсортированной по ключам** —
   это делает пакет `fmt`, а не сам обход.
