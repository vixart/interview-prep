# Решение

## Разбор

1. Объяснить, почему на голой `map` задачу решить нельзя: в Go порядок обхода мапы
   случайный, «самая старая запись» в мапе не хранится.
2. Реализовать вытеснение самых старых записей — классический LRU:
   `map[string]*list.Element` + `container/list` (двусвязный список),
   где список хранит порядок использования, а мапа даёт `O(1)` доступ.
3. При превышении лимита удалять элемент с хвоста списка и соответствующий ключ из мапы.
4. Обсудить сложность операций (`O(1)` на `Get`/`Set`) и потокобезопасность.

Рабочий код: [`solution.go`](solution.go) (запускается: `go run solution.go`).
