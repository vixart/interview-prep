# 4.5.2. Вернуть ошибку из функции, не подключая дополнительных пакетов

Тип задачи: задача на написание кода вживую.

## Условие

> Верни из функции ошибку, не подключая доп. пакеты.

```go
package main

func main() {
    println(handle())
}

func handle() error {
}
```

**Задание:** реализуй возврат ошибки без импорта дополнительных пакетов и объясни, как устроен интерфейс `error`.
