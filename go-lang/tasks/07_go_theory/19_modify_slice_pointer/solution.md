# Решение

## Разбор

1. Предсказать вывод (адрес, `cap`, итоговый `age`).
2. Объяснить:
   - `p1` указывает на элемент backing-массива;
   - `append` трёх элементов превышает `cap == 2`, поэтому создаётся новый массив
     (ёмкость вырастает до 6 — нужно 5 элементов, но runtime округляет до класса
     размера аллокации),
     а `p1` остаётся указателем на **старый** массив;
   - поэтому второй `p1.age++` не виден в `people[1]`.
3. Сформулировать правило: не хранить указатели на элементы слайса,
   который может быть расширен.

## Ожидаемый вывод

```
0x...       (адрес элемента)
6           (новая capacity)
1           (people[1].age — учтён только первый инкремент)
```
