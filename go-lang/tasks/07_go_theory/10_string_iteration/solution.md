# Решение

## Разбор

1. Предсказать вывод и объяснить, почему вместо эмодзи печатается «мусор».
2. Объяснить: `len(str)` — количество байт, `str[i]` — один **байт** (`byte`),
   а эмодзи занимает 4 байта в UTF-8, поэтому по одному байту символ не восстановить.
3. Показать правильный обход:

```go
for _, r := range str {      // r имеет тип rune, индекс — смещение в байтах
    fmt.Printf("%c ", r)
}

// или
for _, r := range []rune(str) {
    fmt.Printf("%c ", r)
}
```

4. Обсудить, когда обход по байтам всё-таки нужен (ASCII, бинарные данные, производительность).
