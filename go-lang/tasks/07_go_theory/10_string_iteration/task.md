# 4.2.3. Итерация по строке: правильный способ обхода

Тип задачи: вопрос с собеседования «что выведет код и как сделать правильно».

## Условие

Дан код (в строке между `G` и `o` стоит эмодзи — многобайтовый символ):

```go
package main

import "fmt"

func main() {
    str := "G🙂o"
    for i := 0; i < len(str); i++ {
        fmt.Printf("%c ", str[i])
    }
}
```

**Задание:** определи, что выведет программа (и скомпилируется ли она), и объясни почему.
