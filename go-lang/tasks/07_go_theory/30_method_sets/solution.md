# Решение

## Разбор

1. Объяснить правило method set: если хотя бы один метод объявлен с указательным
   получателем (`*T`), то интерфейс реализует только `*T`, но не `T`.
   Значение `T` можно передать в интерфейс, только если **все** методы объявлены
   с получателем-значением.
2. Привести получатели к одному виду (все `*T`) и передавать `&creditCard`, `&payPal`.
3. Устранить лишние/дублирующие вызовы `ExecutePayment`.
4. Объяснить, почему компилятор не может «взять адрес» аргумента автоматически
   (адресуемость: у временного значения нет адреса).
