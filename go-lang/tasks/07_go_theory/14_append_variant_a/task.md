# 4.3.2. Append и изменение слайса — вариант A

Тип задачи: вопрос с собеседования «что выведет код и почему».

## Условие

```go
package main

import (
    "fmt"
)

func main() {
    a1 := []int{1, 2, 3, 4, 5}
    a2 := append(a1, 6)
    a3 := append(a1, 7)

    fmt.Println(a1, a2, a3)
}
```

**Задание:** определи, что выведет программа (и скомпилируется ли она), и объясни почему.
