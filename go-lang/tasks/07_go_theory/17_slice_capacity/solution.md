# Решение

## Разбор

1. Предсказать `len` и `cap` на каждом шаге.
2. Объяснить правило: для `s[start:]` новый `len = len(s) - start`,
   новый `cap = cap(s) - start`; указатель сдвигается вперёд, «отрезанная» голова
   становится недоступной (но память не освобождается).
3. Заметить, что `dataNew := make([]int, 0, 3)` тут бесполезен — значение сразу
   перезаписывается результатом функции, аллокация выбрасывается.

## Ожидаемый вывод

```
Изначальный слайс: [1 2 3 4 5], len: 5, cap: 10
Подслайс (1): [2 3 4 5], len: 4, cap: 9
Подслайс (3): [4 5], len: 2, cap: 7
```
