# Решение

## Разбор

1. Предсказать вывод программы.
2. Объяснить:
   - аргументы `defer` вычисляются в момент объявления, поэтому оба `printBalance`
     получили копию `1000`;
   - `printAccountBalance` получил копию **указателя**, поэтому видит изменения,
     сделанные через этот указатель (`1000 + 500 - 200 = 1300`);
   - переприсваивание `account = &Account{Balance: 300}` на отложенный вызов не влияет,
     так как указатель уже скопирован в аргумент `defer`;
   - порядок выполнения — LIFO.

## Ожидаемый вывод

```
Указатель на баланс: 1300
Текущий баланс: 1000
Изначальный баланс: 1000
```
