# 4.1.2. Defer: порядок выполнения и подводные камни

Тип задачи: вопрос с собеседования «что выведет код и почему».

## Условие

Дан код. Нужно сказать, что и в каком порядке он выведет.

```go
package main

import "fmt"

func main() {
    x := 10
    y := 20

    defer func(val int) {
        fmt.Println("x:", val)
    }(x)

    defer func() {
        fmt.Println("y:", y)
    }()

    x = 100
    y = 200

    fmt.Println("Конец main")
}
```

**Задание:** определи, что выведет программа (и скомпилируется ли она), и объясни почему.
