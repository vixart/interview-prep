# Решение

## Разбор

1. Предсказать вывод программы.
2. Объяснить два ключевых момента:
   - `defer` выполняются в порядке LIFO (последний отложенный — первый выполненный);
   - аргументы отложенной функции вычисляются в момент объявления `defer`
     (поэтому `x` «замораживается» со значением 10), а замыкание без аргументов
     читает переменную в момент выполнения (поэтому `y` уже 200).

## Ожидаемый вывод

```
Конец main
y: 200
x: 10
```
