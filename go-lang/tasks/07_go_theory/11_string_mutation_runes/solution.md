# Решение

## Разбор

1. Ответить, скомпилируется ли код (нет: `cannot assign to s[0]` — строка неизменяема).
2. Объяснить, что `println(s[0])` печатает **число** (байт `116` для `'t'`),
   а не символ, потому что `s[0]` имеет тип `byte`.
3. Показать, как правильно поменять первую букву:

```go
b := []byte(s)
b[0] = 'R'
s = string(b)

// для не-ASCII — через руны
r := []rune(s)
r[0] = 'Я'
s = string(r)
```

4. Обсудить, почему строки в Go неизменяемы и что при конвертации происходит копирование.
