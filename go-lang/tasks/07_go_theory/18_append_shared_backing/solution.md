# Решение

## Разбор

1. Предсказать вывод обоих `Println`.
2. Объяснить:
   - `nums[0:2]` даёт `len = 2`, `cap = 3`;
   - в `addNum` один элемент влезает в существующую ёмкость → запись идёт
     в тот же массив, `nums[2]` в `main` становится `4`;
   - в `addNums` двух элементов уже не хватает (`len 2 + 2 > cap 3`) → выделяется
     новый массив, оригинал не меняется.
3. Сформулировать вывод: поведение `append` зависит от `cap`, и полагаться на
   «побочные эффекты» нельзя — функция должна возвращать слайс.

## Ожидаемый вывод

```
[1 2 4]
[1 2 4]
```
