# Решение

## Разбор

1. Предсказать вывод всех четырёх `Println`.
2. Объяснить:
   - почему `updateUser(user)` не меняет `user` в `main` (передача структуры по значению — копия);
   - почему `resetUser(&u)` не меняет `u` в `updateUser` (переприсваивание самого указателя
     меняет только локальную копию указателя, а не то, на что он указывает);
   - как надо было написать `resetUser`, чтобы изменение было видно снаружи
     (`*u = User{Name: "Безымянный"}`).

## Ожидаемый вывод

```
Имя до обновления: Олег
Имя внутри функции [updateUser]: Таненбаум
Имя после вызова функции [resetUser] внутри функции [updateUser]: Таненбаум
Имя после обновления: Олег
```
