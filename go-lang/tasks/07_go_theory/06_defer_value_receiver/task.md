# 4.1.6. Ещё один defer: значение получателя фиксируется в момент объявления

Раздел: `06_one_more_defer`

Тип задачи: вопрос с собеседования «что выведет код и почему».

## Условие

Дан код. Нужно сказать, что он выведет.

```go
package main

import "fmt"

type X struct {
    Val int
}

func main() {
    test()
}

func (x X) S() {
    fmt.Println(x.Val)
}

func test() {
    x := X{Val: 10}
    defer x.S()
    x.Val = 256
}
```

**Задание:** определи, что выведет программа (и скомпилируется ли она), и объясни почему.
