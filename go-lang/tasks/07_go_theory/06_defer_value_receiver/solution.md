# Решение

## Разбор

1. Предсказать вывод.
2. Объяснить: при `defer x.S()` получатель `x` — значимый тип, и он копируется
   в момент объявления `defer`, вместе с аргументами. Поэтому последующее
   `x.Val = 256` на отложенный вызов не влияет.
3. Разобрать, что изменится, если метод объявить с указательным получателем
   (`func (x *X) S()`) — тогда скопируется указатель и напечатается `256`.

## Ожидаемый вывод

```
10
```
