# Решение

## Разбор

1. Предсказать вывод.
2. Объяснить устройство интерфейса: это пара `(тип, значение)`.
   При передаче `s` в `interface{}` тип становится `*SomeStruct`, а значение — `nil`.
   Интерфейс равен `nil` только когда **оба** поля пусты, поэтому `i == nil` — ложь.
3. Показать, как проверить правильно:

```go
if i == nil || reflect.ValueOf(i).IsNil() { ... }

// или через type switch
switch v := i.(type) {
case *SomeStruct:
    if v == nil { /* ... */ }
}
```

4. Связать с классической ошибкой: функция возвращает `*MyError` как `error`,
   и `if err != nil` срабатывает даже когда ошибки не было.
   Правило: возвращать `error` как `nil` напрямую, а не через типизированный указатель.

## Ожидаемый вывод

```
Это не nil!
```
