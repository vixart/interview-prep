# Решение

## Разбор

1. Ответить, скомпилируется ли код и что случится в рантайме.
2. Разобрать:
   - `userReader.(Writer)` — это type assertion интерфейса к интерфейсу;
     она компилируется и проходит успешно, потому что динамический тип `*User`
     реализует `Writer`;
   - а вот `userWriter.Get()` **не компилируется**: у интерфейса `Writer`
     нет метода `Get`, статический тип переменной ограничивает набор методов.
3. Показать безопасную форму с двумя возвращаемыми значениями
   (`w, ok := userReader.(Writer)`) — без неё несовпадение типов даёт панику.
4. Показать `type switch`:

```go
switch v := userReader.(type) {
case Writer:
    v.Create()
case *User:
    v.Get()
default:
    // ...
}
```

5. Обсудить внутреннее устройство интерфейса (`iface`: itab + data) и то,
   почему assertion — операция времени выполнения.
