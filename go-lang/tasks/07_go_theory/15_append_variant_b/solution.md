# Решение

## Разбор

1. Предсказать вывод.
2. Объяснить:
   - `modifyElement` меняет элемент по общему backing-массиву → изменение видно снаружи;
   - в `addElement` у слайса `len == cap == 3`, поэтому `append` создаёт **новый** массив;
     дальнейшая запись `slice[0] = 888` идёт уже в новый массив и снаружи не видна.
3. Сформулировать правило: слайс передаётся по значению (копия заголовка);
   изменение элементов видно, а `append`/переприсваивание — нет.
   Чтобы вернуть результат, функция должна возвращать слайс.

## Ожидаемый вывод

```
До modifyElement: [10 20 30]
После modifyElement: [10 999 30]
До addElement: [10 999 30]
Внутри addElement: [888 999 30 100]
После addElement: [10 999 30]
```
