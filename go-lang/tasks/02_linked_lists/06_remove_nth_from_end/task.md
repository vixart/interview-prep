# 2.1. Удаление N-го элемента с конца односвязного списка

Раздел: `02_linked_lists / 06_remove_nth_from_end`

## Условие

Дан односвязный список и число `n`. Нужно удалить `n`-й элемент с конца списка
и вернуть голову списка.

## Требования

- Решить задачу за один проход по списку.

## Сигнатура

```go
type ListNode struct {
    Val  int
    Next *ListNode
}

func removeNthFromEnd(head *ListNode, n int) *ListNode { return nil }
```

## Примеры

```
Input:  head = [1,2,3,4,5], n = 2
Output: [1,2,3,5]
Объяснение: удаляем 4 (второй элемент с конца)

Input:  head = [1], n = 1
Output: []
Объяснение: удаляем единственный элемент

Input:  head = [1,2], n = 1
Output: [1]
Объяснение: удаляем последний элемент
```
