# Решение

## Разбор и подсказки

- Первый успешный результат «выигрывает» — остальные горутины нужно отменить
  через производный `context.WithCancel`.
- Каналы должны быть буферизованными (или чтение должно продолжаться),
  иначе проигравшие горутины навсегда заблокируются на отправке — утечка горутин.
- Нужно посчитать завершившиеся с ошибкой задачи и вернуть последнюю ошибку,
  только когда все `len(jobs)` задач упали.
- Отдельно обработать пустой список задач и уже отменённый `ctx`.
