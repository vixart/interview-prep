# Решение

## Разбор и подсказки

- Наивное хранение всех timestamp'ов в слайсе растёт неограниченно →
  чистить «хвост» при каждом обращении (скользящее окно / очередь).
- Вариант получше: кольцевой буфер бакетов по секундам (300 бакетов) с
  суммой — `GetCount` за `O(1)`/`O(300)` и константная память на пользователя.
- Синхронизация: `sync.RWMutex` на пользователя или шардированная мапа,
  чтобы не блокировать всех разом.
- Удаление неактивных пользователей (иначе мапа растёт вечно) — фоновый GC-тикер.
