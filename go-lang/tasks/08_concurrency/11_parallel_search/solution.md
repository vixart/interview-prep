# Решение

## Разбор и подсказки

- Запускаем горутину на каждый сервер, результаты собираем в буферизованный канал,
  чтобы «опоздавшие» горутины не залипли навсегда (утечка горутин).
- Как только пришёл первый успешный ответ — возвращаем его и отменяем остальные
  (`context.WithCancel`).
- Считаем количество ошибок; если их столько же, сколько серверов — возвращаем ошибку
  (можно агрегировать через `errors.Join`).
- Дополнительно стоит разобрать вариант с таймаутом на весь поиск
  (`context.WithTimeout`) и вариант через `golang.org/x/sync/errgroup`.
