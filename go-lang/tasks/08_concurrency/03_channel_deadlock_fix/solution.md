# Решение

## Разбор

1. Предсказать поведение и объяснить, почему возникает deadlock:
   на первом же тике `main` пытается **сама** записать в небуферизованный `ch`
   внутри `select`, а читать из `ch` некому — `main` заблокирована на отправке,
   и она же единственный читатель.
   Результат: `fatal error: all goroutines are asleep - deadlock!`
2. Разобрать сопутствующие проблемы:
   - `ticker` не останавливается (`defer ticker.Stop()`) — утечка;
   - горутина через 3 секунды повиснет на `ch <- false`, если main уже вышла —
     утечка горутины;
   - один канал используется и для записи, и для чтения из одного места — плохой дизайн.
3. Исправить: разделить каналы (`tickCh` и `doneCh`), сделать канал буферизованным
   или писать из отдельной горутины, добавить `defer ticker.Stop()` и контекст для выхода.
