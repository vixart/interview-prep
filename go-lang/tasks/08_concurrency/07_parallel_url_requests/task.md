# 4.6.7. Параллельные HTTP-запросы к списку URL

Раздел: `concurrency / 07_request_to_url`

## Исходные данные

```go
package main

func main() {
    var urls = []string{
        "http://ozon.ru",
        "https://ozon.ru",
        "http://google.com",
        "http://somesite.com",
        "http://non-existent.domain.tld",
        "https://ya.ru",
        "http://ya.ru",
        "http://eeeboy",
    }
}
```

## Задача (5 этапов постепенного усложнения)

1. Напишите программу, которая поочерёдно выполнит HTTP-запросы
   по предложенному списку ссылок:
   - В случае получения HTTP-кода `200 OK` печатаем `"url - ok"`.
   - В остальных случаях печатаем `"url - not ok"`.

2. Модифицируйте программу с использованием каналов:
   - Запросы выполняются в горутинах.
   - Печать результатов происходит в основном потоке.

3. Модифицируйте программу без использования длины слайса:
   - Считайте, что URL'ы приходят из внешнего источника.
   - Количество заранее неизвестно.
   - Реализуйте идиоматичный способ сигнализации об окончании
     (закрытие канала + `for range`, `sync.WaitGroup` + горутина-закрыватель).

4. (необязательно) Добавьте отмену через `context`:
   - При получении 2 первых ответов `200 OK` отменить остальные запросы.
   - Напечатать сообщение о завершении/отмене запроса.

5. Ограничьте число одновременных запросов
   (семафор / worker pool) и корректно обработайте ошибки.
