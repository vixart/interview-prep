# Решение

## Разбор и подсказки

- У `http.Client` обязательно задать `Timeout` (например, `5 * time.Second`),
  иначе запрос может висеть бесконечно.
- Обязательно `defer resp.Body.Close()` и вычитывание тела (`io.Copy(io.Discard, resp.Body)`),
  иначе соединение не вернётся в пул — утечка ресурсов.
- `http.NewRequestWithContext` для реальной отмены запроса.
