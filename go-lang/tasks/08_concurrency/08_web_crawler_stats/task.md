# 4.6.8. Web crawler: статистика загрузок за последние 10 минут

Раздел: `concurrency / 08_web_crawler`

## Условие

Реализовать API для web crawler, который отслеживает статистику
загруженных страниц за последние 10 минут.

### Контекст

- Web crawler скачивает страницы с social media платформ.
- Скачанные страницы отправляются в очередь сообщений.
- Нужно предоставить API для получения статистики.

### Требования

- `OnPageDownloaded` вызывается при загрузке каждой страницы.
- `Count` возвращает количество загрузок для хоста за последние 10 минут.
- Учитывать конкурентный доступ (вызовы из нескольких горутин).
- Минимизировать потребление памяти.

## Пример результата

```
facebook.com 452000
twitter.com  321000
linkedin.com 289000
```
