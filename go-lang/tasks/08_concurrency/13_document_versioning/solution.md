# Решение

## Разбор и подсказки

- Состояние по `Url` хранится в мапе; нужен `sync.RWMutex` (или шардированная мапа /
  мьютекс на ключ), чтобы обработка одного `Url` была атомарной.
- Дубликат (`FetchTime` уже виден) → вернуть `nil`.
- Возвращать копию документа, а не указатель на внутреннее состояние.
