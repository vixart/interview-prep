# Паттерны

Конспекты по архитектурным паттернам для подготовки к собеседованию.

| Паттерн | О чём |
|---|---|
| [SOLID](solid.md) | Пять принципов проектирования: SRP, OCP, LSP, ISP, DIP |
| [CQRS](cqrs.md) | Разделение команд (запись) и запросов (чтение) |
| [Active Record, Data Mapper, Unit of Work](orm.md) | Паттерны работы с БД, на которых строятся ORM |
| [Transactional Outbox](outbox.md) | Надёжная публикация событий: атомарность записи в БД и отправки в брокер |
