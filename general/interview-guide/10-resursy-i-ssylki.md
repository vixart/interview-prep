# 10. Ресурсы и ссылки

## Зарплатная аналитика

- [Levels.fyi](https://www.levels.fyi) — компенсации в tech по грейдам и
  компаниям.
- [Glassdoor](https://www.glassdoor.com) — зарплаты и отзывы сотрудников.
- [Robert Half](https://www.roberthalf.com) — зарплатные гайды по рынкам.

Как этим пользоваться: [07-zarplata-peregovory.md](07-zarplata-peregovory.md).

## Поиск контактов и откликов

- **Job Right** — поиск email нанимающего менеджера по ссылке на вакансию
  и странице компании.
- **LinkedIn → страница компании → People** — поиск сотрудников нужной
  команды по ключевому слову из вакансии.

Метод целиком: [03-poisk-raboty-i-otkliki.md](03-poisk-raboty-i-otkliki.md).

## Техническая подготовка

- [System Design Primer](https://github.com/donnemartin/system-design-primer)
  — подготовка к system design интервью.
- [public-apis](https://github.com/public-apis/public-apis) — список
  публичных API (пет-проекты, примеры интеграций).
- [indiehaha.tech](https://indiehaha.tech/) — подготовка к собесу, ревью.

По конкретным технологиям в этом репозитории есть отдельные разделы:
`../../go-lang/`, `../../sql/`, `../../security/`.

## Исходные материалы

Все reels и посты, из которых собрана эта база, перечислены в
`../videos` (список с описаниями) и `../info` (общий список ссылок
по всем темам, не только по собеседованиям).

в Instagram.
